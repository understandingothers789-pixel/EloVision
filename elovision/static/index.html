How to read these predictions ⓘ

These are model predictions of human choices, not measured frequencies or engine evaluations. The most likely move is not necessarily the strongest.

Maia’s 79-million-parameter model scores all legal moves in a single neural-network pass; it does not search chess variations. The model stays loaded during the session, and repeated positions with the same history and ratings use a local result cache.

The official code accepts ratings 0–5000. Its API does not establish rating-specific training or evaluation coverage. Interpret the 400 and 3000 extremes with particular caution; ratings are never silently clamped.

PGN history is used when available. A standalone FEN repeats its current position to fill the eight-position input.
